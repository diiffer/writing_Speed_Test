# ⌨️ Тест скорости печати (BMSTU Edition)

Высокопроизводительное приложение для измерения скорости печати, разработанное в рамках проекта по программированию для первого курса.

## 🚀 Особенности
- **Отслеживание в реальном времени:** мониторинг нажатий клавиш и расчет скорости на лету.
- **Динамическая сложность:** выбор между уровнями «Легкий», «Средний» и «Сложный» для проверки своих сил.
- **Красивый GUI:** интерфейс профессионального уровня, реализованный с помощью Dear ImGui.
- **Точные метрики:** расчет WPM (слов в минуту) и подсчет общего количества ошибок.

## 🛠 Технологический стек
- **Основная логика:** C++17
- **GUI-фреймворк:** [Dear ImGui](https://github.com/ocornut/imgui)
- **Управление окнами:** [GLFW](https://www.glfw.org/)
- **Рендеринг:** OpenGL 3.3

## 📦 Установка и настройка

### Для macOS
Вам понадобится установленный `brew` на вашем macOS.
```bash
brew install glfw
```

### Сборка проекта (macOS)
Проект использует процесс компиляции с линковкой GUI-библиотек. Поскольку это GUI-приложение, вы больше не можете использовать простую команду `g++` без подключения OpenGL и GLFW.

**Рекомендуемая команда для сборки:**
```bash
g++ -std=c++17 WST/*.cpp -lglfw -lGL -lGLU -framework OpenGL -framework Cocoa -framework IOKit -o typing_test
```
*(Примечание: точные флаги могут варьироваться в зависимости от конфигурации вашей системы).*

### Для Windows
1.  **MinGW-w64:** Установите компилятор C++, например, через [MSYS2](https://www.msys2.org/). После установки выполните `pacman -S mingw-w64-x86_64-gcc`.
2.  **GLFW:** Скачайте [скомпилированные бинарные файлы](https://www.glfw.org/download.html) для вашей архитектуры.

**Примерная команда для сборки:**
```bash
g++ -std=c++17 WST/*.cpp -o typing_test -lglfw3 -lopengl32 -lgdi32
```

## 🎮 Как использовать
1. Запустите скомпилированный бинарный файл: `./typing_test` (macOS) или `typing_test.exe` (Windows).
2. Выберите желаемую сложность и количество слов.
3. Нажмите **"Start Test"**.
4. Печатайте эталонный текст максимально точно и быстро.
5. Узнайте свой итоговый WPM и количество ошибок!
